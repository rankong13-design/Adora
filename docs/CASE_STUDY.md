# Adora 产品案例

## Context 与目标用户

小型跨境团队需要为同一商品不断切换市场、广告平台和创意策略。卖家熟悉规格，却未必能把它变成一个可拍摄、可审核且适合当地语言的广告概念。Adora 服务跨境卖家、广告投手和独立站运营，界面中文，广告资产按目标语言输出。

## Problem 与用户痛点

通用聊天工具常把所有结果放在一个对话里：策略差异不清、字幕和镜头不完整、改写覆盖前文、翻译缺少调整理由。用户需要反复粘贴商品信息，难以比较哪一版值得拍摄。这些为产品假设，尚未完成规模化用户研究。

## Product Hypothesis

如果让商品资料成为结构化 Campaign Brief，再把生成、质量检查、迭代与本地化放入同一个工作台，用户能减少重复输入，保留创作选择，并更快输出可审核的资产。评测重点应是可用资产数和迭代质量，而不是生成条数。

## MVP Definition

MVP 必须在无账号、无数据库和无 API Key 的情况下可演示。保留既有 Next.js 项目、Anker 人工精选案例和流式生成能力。增加 Brief 的目标与语气、编辑/版本、七维度评分、改进、比较、本地化、灵感分析与导出。云同步和真实广告数据不在当前完成范围。

## User Flow 与信息架构

Dashboard → Brief → Project Workspace → 比较三种策略 → 选择一个方向 → 生成 → 编辑 → 评分 → 改进 → 比较 → 本地化 → 收藏/导出 → History 重开。Projects 管理 Campaign，History 管理 Creative，Inspiration 帮助借鉴结构。首页按当前浏览器实际 Useful Signals 去重统计，不制作虚假增长数字。

## AI Workflow 与结构化输出

生成输入分别包含商品、受众、活动、市场/平台规则和输出字段形状。事实约束禁止虚构优惠、评价与参数；用户输入作为数据而非系统指令。模型输出通过字段、长度、方向重复和连续 15 秒分镜检查后才写入。单套改进和本地化有独立任务解析，所有实际请求共享额度。

这仍不是事实验证器。卖家填写的特点是待核对陈述，模型也可能写出流畅但不可靠的表达。因此人工事实审核与自动结构检查保持独立。

## Creative Scoring Logic

heuristic-v1 对 Hook、Clarity、Audience、Platform、Value、CTA、Localization 给出 0–100 的结构线索分数、原因与建议。它检查长度、字段、场景线索和 CTA 动词，不理解真实购买意愿。评分不是 CTR / CVR。版本变化使旧分数失效；收藏不影响文案快照。

实际商业评估需要用户选择、真人评审和受控实验共同校准。高分不直接标记为“最佳”，比较区说明适合测试的场景与取舍。

## Iteration 与用户控制

手动编辑保存为 User Edited 新版本；恢复也追加版本，方便回溯。一键改进有七种目标，Demo 是有限模板变换，真实 AI 为服务器请求。Before / After 展示原表达与改进内容。Hook / CTA 变动只同步仍与旧文案一致的脚本文字，不覆盖独立编辑的字幕。

## Localization Design

来源版本与原文一起保存，目标市场、语言、语气明确选择。US / GB 关注拼写与 CTA；东南亚拆为新加坡、印度尼西亚，保留日本。价格没有当地依据时不伪造汇率。Demo 同语言适配有限，跨语言按 Brief 重建模板；UI 和 notes 明确说明，不冒充完整翻译或当地表现保证。

## Failure Handling

模型结构异常最多修正一次；认证、限流、截断和网络失败保留原内容，允许明确选择演示。等待可取消。存储先验证、写成功才更新 UI；损坏原始数据不覆盖，可下载原始备份。普通过期写入通过更新时间拒绝；备份合并不覆盖已有 ID。

## Metrics

North Star 候选：Useful Creative Outputs per Active Project。辅助为创建完成率、生成完成率、编辑后保存率、复制/导出、迭代、本地化与复访。Save / Copy / Export / Iterate / Localize 记录在本地，按版本和本地化 ID 去重；事件适配器未连接分析服务，没有真实用户群体、增长或商业指标。

## Tradeoffs

本地保存让体验无需账号，但同步和并发能力有限。模板带来可演示性，语言质量有限且不能替代模型或当地审核。规则评分可解释但语义判断弱。手动灵感分析可靠地避免依赖 scraper，却不能提供实时竞争趋势。系统字体避免字体网络依赖；原生 dialog 提供键盘焦点与 Escape 行为。

## 验证与未来迭代

自动化覆盖原生成流、解析、Repository、版本变换、评分快照、本地化与导出；浏览器覆盖主要用户闭环和响应式。具体结果见 QA.md。测试用假 provider，不说明真实模型质量已经达标。

下一阶段：以几个真实商品做双语盲评与用户任务测试；确认“可用输出”的定义；用真实任务完成率、方向选择理由、复核成本与采用行为验证产品假设。公网真实 AI 需先部署鉴权、持久额度与成本监控。

面试可讲的核心故事：把分散的商品理解、找角度、按平台改写、翻译、比较和复制，变成一条可回溯的 **Understand → Strategize → Generate → Evaluate → Improve → Localize → Export** 流程。所有能力都有明确来源与限制。
