# 部署与运行

2026-10-04。当前完成本地生产构建；没有创建公网地址或配置云账号。

## 本地生产验证

```sh
npm ci
npm run lint
npm run typecheck
npm run test
npm run build
npm start -- --port 3001
```

推荐 Node.js 24 LTS。start 默认监听127.0.0.1，适合本机演示。不要同时在同一 `.next` 构建和运行开发模式。

## 无密钥公开演示

在支持 Next.js Node 服务的环境安装锁定依赖、构建、启动。托管环境需对外监听时使用 `npm start -- --hostname 0.0.0.0 --port <平台提供的端口>`，由平台处理 HTTPS 与访问路由。

不配置 AI 变量时，本地模板工作流完整可用。不需要数据库或登录；各访客数据留在各自浏览器。域名/端口改变后不会带入旧存储，可备份迁移新 ID。

本次没有选择托管服务、创建云资源或发布，不能将本地构建成功描述为上线。

## 带真实 AI 的部署

服务端配置四个 ADORA_AI 环境变量，见 README 与 .env.example。不要使用 NEXT_PUBLIC_，不要上传 .env.local。已有同源检查、请求体上限、超时、结构校验和进程级6次/小时额度。

公开启用付费服务前需落实用户身份、服务端权限、持久用户/租户额度、供应商预算、成本告警和审计。同源检查不能阻止非浏览器调用者；额度在多实例间不共享，重启重置。当前适合本机真实 AI 演示，不把无鉴权付费接口称为公网生产就绪。

生成最多70秒服务端/75秒页面；单套任务65秒服务端/70秒页面。托管环境需支持这些时长与流式响应，否则应调整执行方式。取消已发出的请求仍可能计费。

## 验证与回退

构建后检查六个页面、未知项目提示、无密钥状态、创建与刷新、版本恢复、导出备份。先在无密钥测试环境验证错误请求，不将验收测试指向付费模型。

发布保留上一个构建及锁文件，故障时回退部署。当前兼容旧存储键，没有破坏性迁移；新字段保持可选并深层校验，未知/损坏数据先备份再处理。
