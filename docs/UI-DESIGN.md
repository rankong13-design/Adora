# Adora Creative Studio · 界面升级

2026-10-06，在现有项目上升级视觉与布局。

## 参考与取舍

实际浏览了 Supahero 收录的 [Attio](https://supahero.io/hero/attio)、[Figma](https://supahero.io/hero/figma) 和 [Linear](https://supahero.io/hero/linear) 页面及界面截图。它们是画廊收录的历史参考，不代表当前产品的完整界面。

| 参考 | 采用的设计原则 | 在 Adora 中的实现 |
| --- | --- | --- |
| Attio | 中性背景、清晰标题、克制按钮、产品结构 | 分组侧栏、轻量顶部栏、层次明确的卡片与表单 |
| Figma | 编辑感排版、几何色块、创意与工具结合 | 首页原创地球图形、灵感示例的琥珀/酸橙/薰衣草封面 |
| Linear | 稳定导航、信息密度与操作层级 | 项目/历史工具栏、结果页工作区与明确的版本对比 |

Adora 保持浅色，因为正文、脚本、表单和并排比较是长时间阅读任务。色彩集中在创作入口和原创教学封面，业务内容区域保持安静。没有引入第三方模板包、外部字体、参考网站图片或新增大依赖；图形使用现有图标与原生 CSS/SVG。

## 页面变化

- 全局：220px 桌面侧栏、分组导航、当前页面状态、品牌标记与 favicon；960px 以下切换紧凑顶部栏和底部导航。辅助文字加深，保留键盘焦点和减少动画偏好。
- 首页：大标题与原创地球图形、三个真实创作入口、真实使用统计、最近项目卡片和创意表达。
- 灵感：三份原创教学示例的视觉封面；输入与 Insight 双栏；12 种结构支持真实目标筛选、搜索、零结果与重置。
- Brief：商品信息、市场与目标、创意线索三个编号分区，右侧实时预览；可选信息折叠，原字段和草稿机制保留。
- 项目与历史：一致的卡片、进度、市场信息、筛选工具栏及版本记录。
- 结果：生成后将方向选择收纳为可展开的当前策略，让广告资产更快进入视野；方向仍可切换。文案、脚本、评分、改进、本地化、对比与导出保持原有流程。

## 数据与验证

本轮 UI 不修改项目存储格式、AI 协议、评分算法或已有用户项目内容。只创建一个明确命名的本地 UI 验收项目用于操作验证。示例、规则分析和 Demo 边界保留；装饰图形不代表真实模型输出、投放效果或用户数据。
