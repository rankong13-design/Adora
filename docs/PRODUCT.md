# Adora — Creative Intelligence for Global Ads

Adora 帮助跨境电商卖家、广告运营和小型出海团队，把商品信息转化为可以审核、修改、比较和导出的广告资产。核心问题并非“不会写一句文案”，而是商品理解、平台策略、市场语言与创意迭代分散在多个工具里，输入与修改结果容易丢失。

## 核心路径

Brief → 三个策略方向 → 选择 → 生成所选方向 → 复制 / 编辑 → 质量检查 → 改进版本 → Before / After / 创意比较 → 本地化副本 → 收藏 → 导出 → 历史重开。

`/` 显示当前浏览器的真实统计、最近项目和创意；`/projects` 管理 Campaign；`/projects/new` 构建 Brief；`/projects/[id]` 为工作台；`/history` 检索创意；`/inspiration` 提供原创教学示例、手动结构分析与 12 个模式。

## Brief

必填商品名称、卖点和目标人群；类别、市场、平台和语气有默认值；语气限定为 Casual / Energetic / Demonstrative / Premium / Minimal / UGC。营销目标默认 Conversion，语言按市场建议，允许独立调整。商品描述、价格、URL、优惠、CTA、痛点、使用情境和证据为可选补充。草稿自动保存，但损坏草稿不会被覆盖。URL 不会被抓取。

## 市场与平台

优先 US / GB 和 TikTok / Meta（Instagram、Facebook 分别选择）。东南亚分别提供新加坡英语与印度尼西亚语场景，保留原有日本市场，不把地区当成同一种文化。平台规则关注首帧、信息密度、字幕安全区与行动提示。规则是创作指导，需要本地语言审核和真实投放验证。

## 用户控制

编辑 Hook、正文、标题、CTA 和分镜，保存为新版本；仅自动同步仍与旧 Hook / CTA 一致的镜头文字，独立编辑的字幕保留。可重新生成所选方向，为对应创意添加版本，保留其他方向与额外副本。恢复旧版本也追加记录。收藏与评分不改写文案。本地化保存源版本、原始内容、目标语言、调整说明和结果。

## 能力边界

- 本地 Mock 采用有限词库和模板，未知特点保留中文、外语使用通用表述。不会验证商品资料。
- 同语言本地化演示调整有限拼写与 CTA；跨语言演示按 Brief 与原方向重建模板，不能当作完整逐句翻译。
- 规则质量评分检测结构线索；人工事实审核是独立环节。分数不是 CTR、CVR 或创意优劣的保证。
- 教学示例为原创，无真实竞争广告数据库。分析仅给结构启发，不传递竞品原文到新 Brief。
- 真实 AI 需服务端配置和外部服务可用；测试不调用付费服务。图片与视频仍为拍摄建议，没有生成成片。

## 产品指标设计

North Star：**Useful Creative Outputs per Active Project**。当前 Useful Signals 为 Save / Copy / Export / Iterate / Localize，按版本与本地化记录去重。它表示用户行为，不能证明内容可用；生成和收藏不计入，应通过用户访谈校准定义。

辅助指标：创建完成率、生成完成率、编辑后保存率、复制/导出率、重新生成率、改进与本地化使用率、项目复访率。事件入口在 `lib/analytics.ts`，默认不向外发送数据；Useful 行为元数据仅保存在当前浏览器。当前没有跨用户漏斗数据；首页统计仅为当前浏览器数据，不是用户增长数字。

评测应分开记录结构失败、事实不可靠、语言不自然和用户未采用。不要把手动评审的小样本比例冒充模型错误率或业务转化率。
